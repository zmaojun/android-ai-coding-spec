# Android 工程治理边界

Android 平台包只提供跨项目可复用的工程边界，不定义任何项目架构、业务规则或类名。

## 线程与生命周期

- 网络、磁盘、重量级数据库与大图处理离开主线程。
- 异步结果写回界面前确认宿主仍处于有效生命周期。
- 回调、观察者、Receiver 和可关闭资源必须成对注册与释放。

## UI 状态

- 页面状态保持单一真源。
- View 层只承担展示、交互和生命周期装配。
- 不并行使用 DataBinding、观察回调和手工属性更新驱动同一展示状态。

## 资源与兼容

- 复用目标项目现有资源、设计 token、导航和服务入口。
- 不把大对象放入 Intent 或 Bundle。
- 不增加依赖、不改变公共 API、不迁移架构，除非已进入人工批准边界。

目标项目自己的规则始终优先；本文件不得承载项目专名或实现路径。
