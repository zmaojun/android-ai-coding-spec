# AI Coding 变更检查清单

## 需求

- [ ] 目标、非目标和验收标准明确。
- [ ] 已识别相关稳定规格和当前变更。
- [ ] 缺失的领域决策已明确人工负责人。

## 分析与设计

- [ ] 已检查现有职责归属与可复用能力。
- [ ] 已考虑直接和间接调用方、数据、API、生命周期、并发及兼容性影响。
- [ ] 已记录风险等级和必需评审人。
- [ ] 新增类、接口、模式、依赖、数据结构或公共 API 已在必要时获得批准。

## 实现

- [ ] 仅修改已批准任务涉及的文件。
- [ ] 未重复实现或推断业务规则。
- [ ] 已处理错误、空值、资源、生命周期、并发和安全路径。
- [ ] 已新增或更新相关测试。

## 评审与验证

- [ ] 已依据验收标准评审实际 diff。
- [ ] 已检查正常、边界、失败和回归场景。
- [ ] 已准确记录命令和结果。
- [ ] 人工、设备、集成和人工评审事项均已明确。

## 交付

- [ ] 已更新 OpenSpec 任务与变更状态。
- [ ] 已列出剩余风险和后续工作。
- [ ] 未将未执行的测试或评审报告为已通过。
